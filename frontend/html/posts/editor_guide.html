Headings and anchors

# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6

A markdown heading gets an id automatically.
The text goes to lower case, the punctuation goes away, and the words join with -. Cyrillic letters change to Latin letters. 

## What Is Reshta?      ->  id="what-is-reshta"
## The save() method    ->  id="the-save-method"
## C++ & Rust           ->  id="c-rust"
## Привіт               ->  id="privit"

The id is what a link such as #what-is-reshta points at.
Two headings with the same text get -1 and -2 at the end, because an id must be unique on the page.

Markdown inside inline code is not parsed, as the third row shows.
To put a backtick in the code, use two backticks on each side: ``a ` b`` gives a ` b.
Inline code gets no colours. Pygments works on blocks only.


A code block.

Four spaces at the start of a line also make a code block, but with no colours.

Images

Upload

![Alt text](https://mykytaso.com/media/photo.jpg "m")

The alt text becomes the caption below the image, and it is what a screen reader reads. Leave it empty for an image with no caption.
The title — "m" above — sets the width.

Table of contents

Write <nav class="toc"> block, and the CSS gives it the title, the bullets and the box. 

<nav class="toc">
  <ul>
    <li><a href="#setup">Setup</a></li>
    <li><a href="#usage">Usage</a>
      <ul>
        <li><a href="#cli">The CLI</a></li>
      </ul>
    </li>
  </ul>
</nav>
  • A child list goes inside the <li> of its parent, never straight inside a <ul>.
  • A category gets a filled bullet, a subcategory a hollow one.
  • Each href must be the same as the id of a heading.

Raw HTML

Markdown cannot do everything.

<h3 align="center" id="my-section">A centred heading</h3>

<p style="text-align:center;">Centred text.</p>

<div class="caption-text">A caption under something that is not an image.</div>

<a href="https://example.com" target="_blank" rel="noopener noreferrer">A new tab</a>

A heading written as raw HTML gets no automatic id.
